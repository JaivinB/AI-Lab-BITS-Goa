The two rows stay identical - in fact both stay exactly zero.  With
W2 = 0 the signal reaching the hidden layer is zero, so dL/dW1 = 0 and
the hidden layer never moves at all.  Only the output bias can learn,
and the best a constant output can do on a balanced XOR table is
p = 0.5 everywhere, i.e. loss ln 2 = 0.693147.

Here the gradients are nonzero, yet the two rows remain identical at
every step.  Identical hidden units compute the same output, so they
receive the same upstream derivative and are updated by the same
amount for ever.  The 2-2-1 network therefore behaves as a 1-hidden-
unit network, whose decision boundary is a single line - and one line
cannot separate XOR.  This is the symmetry problem proper; C1 is the
degenerate special case in which the gradient also vanishes.
Random initialisation is what breaks the symmetry.
